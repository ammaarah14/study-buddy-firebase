# 📚 Study Buddy

A clean, cross-platform study planner built with **Flutter** and **Firebase**. Sign up, organise your coursework into subjects, track tasks with priorities and due dates, and watch your progress bar fill as you get things done. Everything syncs in real time through Cloud Firestore.

## ✨ Features

- **Authentication** – email/password sign up, log in and log out via Firebase Auth, with an auth gate that automatically routes users to the right screen.
- **Task management** – create tasks with a title, optional subject, priority (Low / Medium / High) and optional due date. Tick tasks off or delete them.
- **Subjects** – create and delete subjects to keep your work organised.
- **Dashboard** – a progress card showing completed vs. total tasks, quick actions, and your five most recent tasks.
- **Real-time sync** – all data is streamed from Firestore, so changes appear instantly across devices.
- **Per-user data** – each user's tasks and subjects live under their own `users/{uid}` document.
- **Material 3 UI** – a soft green theme with rounded cards and inputs.
- **Multi-platform** – Android, iOS, Web, Windows, macOS and Linux targets are all scaffolded.

## 🗄️ Data Model

All data is scoped to the signed-in user:

```
users/{uid}
├── email: string
├── createdAt: timestamp
├── tasks/{taskId}
│   ├── title: string
│   ├── subject: string          (defaults to "General")
│   ├── dueDate: timestamp | null
│   ├── priority: "Low" | "Medium" | "High"
│   ├── completed: bool
│   └── createdAt: timestamp
└── subjects/{subjectId}
    ├── name: string
    ├── colorValue: int          (ARGB, defaults to 0xFF4F6F52)
    └── createdAt: timestamp
```

## 🚀 Getting Started

### Prerequisites

- [Flutter SDK](https://docs.flutter.dev/get-started/install) with Dart `3.13.3` or newer
- A Firebase project (see below)
- [Firebase CLI](https://firebase.google.com/docs/cli) and [FlutterFire CLI](https://firebase.flutter.dev/docs/cli) (only needed if you connect your own Firebase project)

### 1. Clone and install

```bash
git clone <your-repo-url>
cd study-buddy-firebase
flutter pub get
```

### 2. Set up Firebase

The repo ships with a `firebase_options.dart` and `google-services.json` for an existing Firebase project. To run against **your own** project instead:

1. Create a project in the [Firebase console](https://console.firebase.google.com/).
2. Enable **Authentication → Sign-in method → Email/Password**.
3. Create a **Cloud Firestore** database.
4. Regenerate the platform config:
   ```bash
   dart pub global activate flutterfire_cli
   flutterfire configure
   ```
   This overwrites `lib/firebase_options.dart`, `android/app/google-services.json` and `firebase.json` with your project's values.

### 3. Add Firestore security rules

Restrict each user to their own data. In the Firebase console (Firestore → Rules), or in a `firestore.rules` file deployed with the Firebase CLI, use:

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{userId}/{document=**} {
      allow read, write: if request.auth != null && request.auth.uid == userId;
    }
  }
}
```

### 4. Run the app

```bash
flutter run                 # pick a connected device or emulator
flutter run -d chrome       # web
flutter run -d windows      # or macos / linux
```

## 🛠️ Troubleshooting

- **"Could not load your tasks"** – Firestore isn't enabled for your project, or your security rules are blocking the signed-in user. Check step 3 above.
- **Sign-in fails with a config error** – make sure Email/Password sign-in is enabled in the Firebase console.
- **Firebase initialisation errors after switching projects** – re-run `flutterfire configure`, then `flutter clean && flutter pub get`.
- **Android build issues** – confirm `android/app/google-services.json` matches your Firebase project and the `applicationId` (`com.example.study_buddy_firebase`).
